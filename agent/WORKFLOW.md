# WP-KIT Master Workflow

## Phase 1 — Discovery

Determine:

- WordPress version;
- PHP version;
- database type/version;
- active theme;
- active plugins;
- custom code;
- hosting/development environment;
- existing integrations;
- relevant project memory.

## Phase 2 — Requirements

Convert the user's request into explicit functional and non-functional
requirements.

Identify:

- pages;
- content types;
- user roles;
- workflows;
- integrations;
- forms;
- administrative requirements;
- SEO requirements;
- performance requirements;
- security requirements.

## Phase 3 — Architecture

Choose the appropriate combination of:

- theme;
- child theme;
- custom plugin;
- custom post types;
- taxonomies;
- metadata;
- REST API;
- AJAX;
- block/editor integration;
- template architecture.

Avoid putting business logic unnecessarily inside a theme.

## Phase 4 — Plan

Break the work into small, testable implementation tasks.

## Phase 5 — Implement

Implement in dependency order.

## Phase 6 — Review

Review all changed files and integration points.

## Phase 7 — Quality Gates

Run the applicable:

- security checks;
- SEO checks;
- performance checks;
- accessibility checks;
- responsive checks;
- functional tests.

## Phase 8 — Memory

Update project memory with completed work, remaining work, and important
architectural decisions.
