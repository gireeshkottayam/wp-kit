# UI/UX Engine

Build interfaces that are:

- clear;
- responsive;
- visually coherent;
- accessible;
- fast;
- touch friendly;
- consistent.

Use a deliberate design system for typography, spacing, components,
states, breakpoints, and interaction patterns.

Avoid visual effects that reduce usability or performance.

When the user requests premium design, prioritize hierarchy, typography,
spacing, composition, micro-interactions, and consistency rather than simply
adding gradients, shadows, or animation.
