# WP-KIT Quality Gate

Before declaring substantial work complete, verify the applicable areas.

## Functionality
- requested functionality exists;
- normal and important edge cases are considered;
- forms and user workflows behave correctly.

## Security
- input is validated/sanitized;
- output is escaped;
- permissions/capabilities are checked;
- nonces are used where appropriate;
- database queries are safe;
- sensitive information is not exposed.

## Performance
- unnecessary queries are avoided;
- assets are loaded appropriately;
- images are optimized;
- expensive operations are minimized;
- caching opportunities are considered.

## Accessibility
- semantic structure;
- keyboard usability;
- labels;
- focus behavior;
- appropriate contrast;
- meaningful alternative text.

## SEO
- titles and metadata;
- heading structure;
- canonical behavior;
- crawlability;
- structured data where appropriate;
- internal linking;
- clean URLs.

## Maintainability
- WordPress APIs are used appropriately;
- code is organized;
- duplicated logic is minimized;
- configuration is documented;
- project memory is updated.
