# Antigravity

Open the WordPress project folder in Antigravity.

Make WP-KIT available inside the project and instruct the coding agent to read
`AGENTS.md`.

Recommended first instruction:

```text
Read AGENTS.md and the WP-KIT agent files before making any changes.
Inspect the entire WordPress project and its .wp-kit memory.
Do not modify code until you understand the existing architecture.
```

For an update, update the WP-KIT repository and then ask the agent to reload
the current WP-KIT instructions before continuing work.
