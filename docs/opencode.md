# OpenCode

Open the WordPress project directory.

Ensure `AGENTS.md` is visible to the agent and WP-KIT files are available.

Start a session with:

```text
Load WP-KIT instructions from AGENTS.md and agent/.
Read the project memory under .wp-kit/.
Inspect the existing WordPress architecture before implementing the request.
```

After updating WP-KIT, reload the project instructions before starting a new
development task.
