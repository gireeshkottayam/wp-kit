# WAMP

Recommended local project directory:

```text
C:\wamp64\www\my-wordpress-site
```

Start Apache and MySQL through WAMP.

Create the WordPress database in phpMyAdmin.

Open:

```text
http://localhost/my-wordpress-site/
```

If using a virtual host, use the configured local domain instead.

Keep local credentials and environment-specific configuration outside any
public repository.

Before moving to production, review:

- site URL;
- home URL;
- database credentials;
- HTTPS;
- file permissions;
- caching;
- mail;
- external API credentials;
- payment integrations;
- scheduled tasks.
